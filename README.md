One museum label from the year 3000, placed beside an ordinary object from today — a group chat, misread as a communal hall where forty-seven people gathered daily to read each other's messages and answer almost none of them.

> Group chat (c. 2024). A communal hall where 47 people gathered daily to read each other's messages and answer almost none of them.

## How it works

`main.py` (Python 3 standard library only) writes the label to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line, and a catalogue date in the museum's own style.

```sh
python3 main.py
```
